# Άγιος Νεκτάριος — Εξωραϊστικός Σύλλογος Βιλίων

Next.js 16 (App Router, Turbopack) site for the settlement of Άγιος Νεκτάριος
on Mount Kithairon. It has two parts beyond the public pages:

- **Διαχείριση** (`/admin`) — an administrator logs in and edits every text on
  the site, uploads photographs and documents, and tunes the background.
- **Ζωντανό σκηνικό** — a canvas backdrop that follows the real sun, moon,
  weather, season and feast day at the village.

## Ανάπτυξη

```bash
npm install
npm run dev
```

## Διαχείριση περιεχομένου

Ο διαχειριστής συνδέεται στο `/admin/login` και μπορεί να αλλάξει:

| Σελίδα | Τι ρυθμίζει |
| --- | --- |
| `/admin/home` | Κάθε κείμενο της αρχικής: τίτλοι, εισαγωγή, αριθμοί, ενότητες, ΔΣ, νέα, επικοινωνία |
| `/admin/pages` | Τίτλο και κείμενο κάθε εσωτερικής σελίδας (WYSIWYG ή απευθείας HTML) |
| `/admin/media` | Ανέβασμα φωτογραφιών και PDF, με έτοιμο σύνδεσμο για επικόλληση |
| `/admin/scene` | Ρυθμίσεις ιστότοπου και ζωντανού φόντου |

Κάθε αποθήκευση εμφανίζεται αμέσως στον ιστότοπο — δεν χρειάζεται νέο deploy.
Το κουμπί «Επαναφορά» σε κάθε σελίδα γυρίζει στο αρχικό κείμενο.

### Μεταβλητές περιβάλλοντος (Netlify → Site configuration → Environment variables)

| Μεταβλητή | Υποχρεωτική | Περιγραφή |
| --- | --- | --- |
| `ADMIN_PASSWORD_HASH` | ναι¹ | Κωδικός διαχειριστή σε μορφή `scrypt:<salt>:<hash>` |
| `ADMIN_USERNAME` | όχι | Όνομα χρήστη, προεπιλογή `admin` |
| `ADMIN_SESSION_SECRET` | συνιστάται | Τυχαία συμβολοσειρά ≥ 16 χαρακτήρων για την υπογραφή του cookie |
| `ADMIN_PASSWORD` | εναλλακτικά¹ | Κωδικός σε απλό κείμενο — λιγότερο ασφαλές |
| `CONTENT_DATA_DIR` | όχι | Φάκελος αποθήκευσης εκτός Netlify (προεπιλογή `.data`) |

¹ Χρειάζεται ένα από τα δύο. Χωρίς αυτά η σύνδεση απορρίπτεται και η σελίδα
σύνδεσης το εξηγεί.

Δημιουργία hash:

```bash
node scripts/hash-password.mjs "ο-κωδικός-σας"
```

### Πού αποθηκεύεται το περιεχόμενο

- **Στο Netlify:** [Netlify Blobs](https://docs.netlify.com/build/data-and-storage/netlify-blobs/)
  (store `agios-nektarios-content`), χωρίς ρύθμιση και χωρίς βάση δεδομένων.
- **Τοπικά ή σε άλλον host:** απλά αρχεία στον φάκελο `.data/`.

Τα αρχικά κείμενα των εσωτερικών σελίδων παραμένουν στο `content/legacy/` και
χρησιμοποιούνται όσο δεν έχει γίνει επεξεργασία.

## Το ζωντανό σκηνικό

`src/scene/` — **αρχή σχεδίασης: τίποτα δεν ζωγραφίζεται πάνω στη φωτογραφία.**
Ό,τι έχει περίγραμμα προδίδεται ως σχέδιο δίπλα σε πραγματικά pixel. Το
σκηνικό στηρίζεται στη φωτογραφία, στο φως πάνω της, και σε ό,τι θα κατέγραφε
ένας φακός.

**Η φωτογραφία.** Το πανόραμα του συλλόγου, περασμένο από Real-ESRGAN ×4
(862 → 3448 pixel) και κομμένο σε δύο επίπεδα με αφαιρεμένο τον ουρανό
(`public/scene/*.webp`). Πριν το feather, το χρώμα της πλαγιάς «ματώνει» προς
τα πάνω ώστε να μη μείνει φωτεινό περίγραμμα στην κορυφογραμμή, και το πάνω
επίπεδο επαναλαμβάνει την τελευταία του σειρά προς τα κάτω ώστε να μη φαίνεται
ραφή με το δάσος μπροστά.

**Ο renderer** (`src/scene/gl/`) είναι WebGL2, δύο περάσματα:

1. *Σκηνή* — ουρανός, αστέρια, ήλιος, σελήνη με σωστή φάση, σύννεφα, βροχή,
   χιόνι, πουλιά· και η φωτογραφία, όπου **ο άνεμος μετακινεί τα ίδια της τα
   pixel**: το shader ξεχωρίζει τη βλάστηση και την ταλαντώνει σε δύο
   συχνότητες, με πλάτος ορισμένο σε pixel οθόνης ώστε να μην αλλάζει με το
   ζουμ. Ο βράχος μένει ακίνητος.
2. *Φακός* — ακτίνες ηλίου μέσα από τη θολή σκηνή, bloom από την αλυσίδα
   mipmap, χρωματική εκτροπή προς τις γωνίες, κόκκος που ανεβαίνει στις σκιές.

Ο χρόνος καρέ παρακολουθείται: αδύναμη συσκευή παίρνει λιγότερα pixel αντί για
slideshow. Όπου λείπει WebGL2 πέφτει σε renderer καμβά (`engine.ts`), που
κρατά και το παλιό ζωγραφισμένο σκηνικό για την περίπτωση που ο διαχειριστής
ανεβάσει δικά του επίπεδα.

**Το φως.** Θέση ήλιου και σελήνης με τύπους Meeus για τις συντεταγμένες του
οικισμού — αληθινή ανατολή, χρυσή ώρα, γαλάζια ώρα, φάση σελήνης. Ο ουρανός
χαρτογραφείται πανοραμικά (260°) ώστε ήλιος και φεγγάρι να μένουν στο κάδρο
όσο είναι πάνω από τον ορίζοντα. Σύννεφα κρύβουν τον δίσκο πολύ πριν κρύψουν
το φως, και το φεγγάρι είναι χλωμό την ημέρα.

**Ο καιρός.** Ζωντανά δεδομένα από το Open-Meteo κάθε δέκα λεπτά μέσω του
`/api/weather`.

**Οι εποχές** χρωματίζουν τη φωτογραφία: πράσινο την άνοιξη, η πλαγιά
ξεραίνεται προς το άχυρο το καλοκαίρι και το φθινόπωρο, κρύα και γαλάζια τον
χειμώνα, με χιόνι όταν χιονίζει.

**Ο οικισμός είναι σκοτεινός τη νύχτα** — παραθεριστικός οικισμός χωρίς
οδοφωτισμό. Δεν υπάρχουν αναμμένα παράθυρα.

**Οι γιορτές** ντύνουν τη σελίδα, όχι τη φωτογραφία
(`components/HolidayDressing.tsx`): κορδέλα στο πάνω άκρο, γιρλάντα με
λαμπάκια για Χριστούγεννα, Πρωτοχρονιά, Πάσχα και τη γιορτή του Αγίου
Νεκταρίου, και η ελληνική σημαία στις 25 Μαρτίου και στις 28 Οκτωβρίου, που
κυματίζει μέσω κινούμενου φίλτρου παραμόρφωσης. Η γιρλάντα μετριέται στο
πραγματικό πλάτος του παραθύρου, οπότε δεν παραμορφώνεται ούτε κόβεται.

Όλα σέβονται το `prefers-reduced-motion` και παγώνουν όταν η καρτέλα δεν είναι
ορατή.
